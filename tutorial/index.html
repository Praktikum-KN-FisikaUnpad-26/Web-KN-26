Rubrik Penilaian

ASPEK PENILAIAN

Harap perhatikan rentang kriteria penilaian berikut sebelum menyusun laporan praktikum.

100 - 83

Laporan lengkap (termasuk pengerjaan tugas tambahan), sesuai dengan format resmi yang ditetapkan, program beserta tampilan tersusun rapi dan mudah diinterpretasikan, dianalisis secara logis, serta kesimpulan memuat seluruh poin yang substansial.

82 - 75

Tidak semua program dianalisis secara logis dan menyeluruh, serta bagian kesimpulan hanya memuat sebagian poin penting dari tujuan praktikum.

74 - 65

Komponen lengkap sesuai format laporan, namun struktur program dan tata letak tampilan kurang rapi. Seluruh program diselesaikan meskipun terdapat kekeliruan pengerjaan. Kesimpulan tidak memuat poin-poin yang relevan.

65 - 45

Laporan tidak lengkap dan tidak tersusun rapi. Banyak pengerjaan program yang tidak diselesaikan. Analisis dan penyusunan kesimpulan dikerjakan secara tidak memadai.

Instruksi Penting

Peraturan Wajib

Sebelum memulai penyusunan, mohon pahami ketiga peraturan utama berikut agar proses penyusunan laporan berjalan dengan lancar.

Dilarang Mengubah File Lain

Anda hanya diperkenankan mengedit 3 file: 01-Inizio.tex, 02-Copyright.tex, dan 03-Content.tex. File konfigurasi lainnya (seperti package dan class bawaan) dilarang keras untuk dimodifikasi.

Penyimpanan File Sesuai Folder

File berekstensi .py wajib ditempatkan pada Folder Code-Python/ dan Screenshot pada Folder Picture/. Dilarang menggabungkan atau menyimpannya di luar dari Folder yang telah ditentukan.

Kompilasi Langsung dari 03-Content.tex

File 03-Content.tex sekaligus berfungsi sebagai File utama kompilasi. Tetapkan selalu 03-Content.tex sebagai Main File di platform Prism. Apabila terdapat Error, perbaiki kode terlebih dahulu sebelum mengompilasi ulang.

Langkah Penyusunan

Panduan Pengisian Template

Ikuti tahapan berikut secara berurutan. Anda hanya perlu mengedit tiga File utama secara sistematis.

File 1 — Cover/[EDIT HERE] Main-Cover/01-Inizio.tex

File ini berfungsi untuk mengatur halaman Cover depan laporan. Harap hanya mengubah tiga variabel berikut dan membiarkan perintah (Syntax) lainnya tetap utuh.

Bagian yang Memerlukan Perubahan

\Relatore{}

Ubah bagian ini dengan nama lengkap Asisten Praktikum modul Anda.

\Candidato{}

Ubah bagian ini dengan nama lengkap Anda.

\Matricola{}

Ubah bagian ini dengan NPM Anda.

Contoh Hasil Pengisian 

\Relatore{
  \large Nama Asisten Modul
}
\RelatoreLabel{\Large Asisten Praktikum}
\CandidatoLabel{\Large Nama}

\Candidato{
  \large Nama Lengkap Anda
}
\Matricola{
  \large 140310240001
}
\DataEsame{\today}
Dilarang mengubah perintah \Titolo{}, \Logo{}, maupun struktur standar lainnya.

File 2 — 02-Copyright.tex

Bagian ini memuat halaman pernyataan orisinalitas pengerjaan laporan. Silakan lakukan pencarian pada teks berikut dan edit sesuai dengan identitas Anda:

Teks Asal (Pencarian) 

Saya \textbf{[Nama - 140310210000]}
selaku \textit{author}...

Teks Pengganti 

Saya \textbf{Nama Anda - 140310240001}
selaku \textit{author}...
Ubah teks yang berada di dalam tanda kurung siku [ ]. Harap tidak merombak struktur kalimat orisinalitas lainnya.

File 3 — 03-Content.tex  — File Utama Kompilasi & Isi Laporan

File ini sekaligus merupakan File kompilasi utama

03-Content.tex sudah mengintegrasikan seluruh konfigurasi dokumen, pemanggilan Cover, Copyright, dan semua konten akademis dalam satu file. Tetapkan file ini sebagai Main File di Prism saat kompilasi — tidak perlu berpindah file.

Seluruh muatan akademis laporan praktikum disusun pada File ini. Terdapat dua bagian yang perlu dilengkapi: Identitas & Header di bagian atas file, lalu Konten Laporan di bagian bawahnya.

A Identitas & Header — Bagian Atas 03-Content.tex

Bagian paling atas file memuat konfigurasi identitas yang akan ditampilkan pada header setiap halaman laporan. Ubah nilai-nilai berikut sesuai data diri Anda:

Field yang Diubah

\journalname{\Large Modul X - ...}

Nama modul praktikum yang sedang dikerjakan.

\author[first author]{\LARGE ...}

Nama lengkap dan alamat email Unpad Anda.

\affil[NPM]{\Large 14031025XXXX, ...}

NPM Anda (10 digit).

\professor{\large Asisten Praktikum : ...}

Nama asisten modul Anda.

\theday{DD Month, YYYY}

Tanggal pengerjaan laporan.

\leadauthor{Nama Belakang et al.}

Nama belakang Anda untuk footer halaman.

Contoh Pengisian 

\journalname{\Large Modul 3 - Persamaan Non-Linier}
\title{Laporan Akhir Praktikum
  Komputasi Numerik (with \LaTeX)}

\author[first author]{
  \LARGE Budi Santoso,
  budi24001@mail.unpad.ac.id
}
\singlespacing

\affil[NPM]{
  \Large 140310250001,
  Departement of Physics -
  Universitas Padjadjaran
}
\singlespacing

\professor{
  \large Asisten Praktikum :
  Nama Asisten Modul
}

\theday{12 March, 2025}
\leadauthor{Santoso et al.}
Letakkan pasfoto formal Anda dengan nama foto.jpg di dalam Folder Picture/ — foto akan tampil otomatis di sudut kanan atas laporan.

Tahap Akhir

⚙️ Prosedur Kompilasi

Setelah seluruh File diedit, lakukan kompilasi menjadi dokumen PDF menggunakan platform Prism. Pastikan 03-Content.tex ditetapkan sebagai Main File.

1

Akses Prism dan Inisialisasi Proyek Baru

Akses platform Prism, kemudian buat proyek baru atau impor Template yang telah Anda Download. Pastikan hierarki Folder tidak berubah setelah diunggah. Upload pula File .py ke Code-Python/, Screenshot ke Picture/, dan pasfoto dengan nama foto.jpg ke Picture/.

2

Tetapkan 03-Content.tex sebagai Main File

Di panel Prism, klik kanan pada 03-Content.tex dan pilih "Set as Main File" (atau opsi serupa). File ini sudah memuat semua konfigurasi dokumen, pemanggilan Cover, dan Copyright — tidak perlu berpindah file sama sekali.

3

Verifikasi Tampilan Preview PDF

Prism dilengkapi Editor teks dan mode Preview PDF terintegrasi. Apabila Preview gagal terkompilasi, tinjau Error Log yang ditampilkan Prism dan lakukan perbaikan kode pada baris yang direferensikan sebelum mengompilasi ulang.

4

Export Dokumen PDF

Setelah kompilasi berjalan sempurna tanpa Error, tekan fitur Export PDF untuk men-Download hasil final. Sangat dianjurkan meninjau kelengkapan rubrik dokumen PDF sebelum diserahkan kepada Asisten Praktikum.

Indikasi Error Umum dan Pemecahannya

File not found: namafile.py

File .py belum di-Upload atau terdapat ketidakcocokan penamaan. Periksa kembali Folder Code-Python/.

File not found: gambar.jpg

Berkas visual belum di-Upload di Picture/ atau terdapat kekeliruan format ekstensi (.jpg/.png).

Undefined control sequence

Terjadi kesalahan pengetikan perintah LaTeX. Tinjau baris Error yang ditampilkan Prism.

Missing $ inserted

Terdapat simbol atau persamaan matematis yang belum diapit oleh indikator $ ... $.

Apabila Error tidak dapat diselesaikan secara mandiri, silakan berkonsultasi dengan Asisten Praktikum atau Penanggung Jawab (PIC) kelompok Anda.

Selamat Mengerjakan

Silakan men-Download Template, membukanya melalui platform Prism, menetapkan 03-Content.tex sebagai Main File, lalu mengedit dan mengompilasi langsung dari situ. Apabila terdapat pertanyaan, jangan ragu menghubungi Asisten Praktikum atau Penanggung Jawab kelompok.
